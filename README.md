# LingoSprout

A Chrome extension prototype for contextual language learning through everyday web reading, vocabulary practice, spaced review and guided conversation.

## Quick start

1. Click **Code → Download ZIP** on this repository and unzip the download.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the folder containing `manifest.json`.
5. Open the LingoSprout extension popup and click **Open demo article**.
6. Click **Start learning**, then click a highlighted word to explore its meaning, save it and give feedback.
7. Open **My learning space** to explore review, quizzes, grammar practice and guided conversation.

## Features

- Contextual vocabulary support while reading
- Saved vocabulary and learner feedback
- Spaced review and vocabulary quizzes
- Grammar practice and guided conversation
- A personal learning dashboard

## Demo mode

The default demo uses prepared offline examples. No API key, model download or server is required.

For optional live AI configuration, see [AI setup](docs/AI_SETUP.md).
